1. QUICK START GUIDE (HOW TO RUN IN 3 MINUTES)
--------------------------------------------------------------------------------

Prerequisites:
- Python 3.10, 3.11, or 3.12 installed on your computer.
- Python should be added to your system PATH.

Step 1: Open Terminal / Command Prompt / PowerShell
Navigate into the "project/electricity" directory:
   cd project\electricity

Step 2: Install Required Libraries (Run once)
   pip install -r requirements.txt

   (Alternative manual command: pip install django pandas numpy scikit-learn reportlab)

Step 3: Start the Django Development Server
   python manage.py runserver

   If port 8000 is occupied on your computer, run:
   python manage.py runserver 127.0.0.1:8080

Step 4: Open in Web Browser
   Go to: http://127.0.0.1:8000/ (or http://127.0.0.1:8080/)
